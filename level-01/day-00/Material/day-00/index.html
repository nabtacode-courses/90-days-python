Before writing your first Python program, let's prepare your development environment.

Installation Checklist

  • Install Python 3
  • Enable: Add python.exe to PATH
  • Install VS Code
  • Install Python Extension by Microsoft
  • Install Git (we will use it later)
Important:

During Python installation, make sure you check:
Add python.exe to PATH

This allows you to run Python commands from the Terminal.

Terminal Commands You Will Use

Terminal 

# Check Python installation

python --version


# Windows alternative

py --version


# Check Git installation

git --version


# Run a Python file

python file_name.py


# Windows alternative

py file_name.py

Common Beginner Mistakes

  • Installing Python without enabling PATH.
  • Creating files like: program.py.txt instead of: program.py
  • Writing Terminal commands inside Python files.
  • Installing too many VS Code extensions.
Setup Ready Checklist:

✓ Python installed
✓ VS Code installed
✓ Python Extension installed
✓ Terminal works correctly
✓ python --version shows a version
# If that does not work: py --version
Expected output: Python 3.x.x. Your exact version may be different.

Install Visual Studio Code

  1. Download and open the VS Code installer.
  2. Accept the license agreement.
  3. Keep the default installation location.
  4. Enable Add to PATH if the option appears.
  5. Complete the installation and open VS Code.

Install the Python Extension

  1. Open the Extensions tab in VS Code.
  2. Search for Python.
  3. Choose the extension published by Microsoft.
  4. Click Install.
Keep your setup light. You only need the essential extensions at the beginning.
  1. Create a normal folder anywhere on your computer. You can name it python-practice.
  2. Open VS Code and choose File > Open Folder.
  3. Select the folder you just created.
  4. Create a new file named first_program.py.
Correct: first_program.py
Incorrect: first_program.py.txt

Write this inside first_program.py:

first_program.py
print("Python is ready!")
print("VS Code is ready!")
print("My Python journey starts today.")

print() displays content on the screen. Text goes inside quotation marks, and Python runs code from top to bottom.

Run it in VS Code

  1. Save with Ctrl + S.
  2. Click Run Python File.

Run it from Terminal

Terminal
python first_program.py
# On some Windows devices, use:
py first_program.py

Python was not found

Try py --version. If the issue remains, reopen Terminal, restart VS Code, or reinstall Python with PATH enabled.

Old output still appears

Save the file with Ctrl + S, then run it again.

Running the wrong file

Confirm you are running first_program.py.

Missing quotation mark

Incorrect vs correct
# Incorrect
print("Python is ready!)

# Correct
print("Python is ready!")

Capital P in Print

Print("Hello") is incorrect; use print("Hello"). Python is case-sensitive.
